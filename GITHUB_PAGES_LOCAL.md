## How It's Built

### Daily Process (GitHub Actions)
1. **Checkout** code from git
2. **Install dependencies** (Python watchers)
3. **Run watchers** (civic data collectors):
   - Agendas from Legistar
   - Contracts from procurement APIs
   - Money from campaign finance APIs
   - Donations from PAC records
   - Legislation from legislative APIs
   - Testimony from meeting minutes
   - Federal grants from USASpending
4. **Seed reports** (committed historical data)
5. **Build static site** (`build_site.py`):
   - HTML generation from data
   - Templating & styling
   - Link resolution
   - Navigation generation
6. **Self-check** (integrity validation):
   - Link verification
   - Mobile responsiveness check
   - External link health
7. **Deploy to GitHub Pages** (automatic)
8. **Notify** private King on success

### Files Involved
- `watchers/*.py` — Data collectors
- `build_site.py` — HTML generator
- `govos.css` — Styling
- `govos-shell.js` — Frontend logic
- `seed_reports/` — Committed historical data
- `site/` — Built output (297 pages)

## Update Behavior

### Auto-Updates (Cron)
- **Frequency**: Daily at 15:20 UTC (~05:20 HST)
- **What updates**: All watchers run, fresh API fetches
- **Deployment**: Auto-deploy to GitHub Pages + local server
- **Trigger**: `.github/workflows/publish.yml` (schedule)

### Push-Triggered Updates
- **Trigger**: Push to `main` branch
- **Paths**: `watchers/`, `build_site.py`, `govos.css`, `seed_reports/`, etc.
- **Speed**: 5-10 minutes (depends on watcher completion)

### Manual Updates
- **Trigger**: Run `publish.yml` from Actions tab (workflow_dispatch)
- **Speed**: Same as push-triggered (~5-10 min)
